1. Time Complexity: Time complexity does not mean execution time. Its a rate of change in time per execution. For example if two input takes 1 sec to execute on computer A and 2 seconds in computer B then for 4 inputs computer A will take 2 sec and computer B will take 4 seconds. we can notice that the rate of execution time changes constantly.
    - Notations:
        1. Big O:Worst Case Scenario
        2. Theta:Average Case Scenario
        3. Omega:Best Case Scenario

While solving DSA realated problem always prioritize the worst case scenario.

2. Space Complexity: Input Space + auxiliary space.
    - Input Space: The memory space taken by input
    - Auxiliary space: The memory space taken by the space we assign while writing code.

\*Some terms: Const operations, Upper bound, lower bound
